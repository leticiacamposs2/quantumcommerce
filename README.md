# QuantumCommerce

Uma aplicação de e-commerce moderna construída com tecnologias de ponta para oferecer uma experiência de usuário excepcional.

## 📋 Visão Geral

QuantumCommerce é um projeto de plataforma de comércio eletrônico desenvolvido com **TypeScript** e **React**, utilizando as mais recentes bibliotecas e frameworks do ecossistema JavaScript moderno.

## 🛠️ Stack Tecnológico

### Frontend
- **React 19.2.0** - Biblioteca UI
- **TypeScript** - Tipagem estática (97.4% do código)
- **TailwindCSS 4.2.1** - Framework de estilização
- **Vite 7.3.1** - Build tool rápido e moderno

### Roteamento e Navegação
- **TanStack React Router 1.168.25** - Sistema de roteamento
- **TanStack React Start 1.167.50** - Meta-framework fullstack
- **TanStack Router Plugin 1.167.28** - Plugin para otimizações

### Estado e Query
- **TanStack React Query 5.83.0** - Gerenciamento de estado assíncrono

### UI Components
- **Radix UI** - Componentes acessíveis e sem estilo
- **Lucide React** - Ícones SVG
- **Cmdk** - Command menu/palette
- **Embla Carousel** - Carrossel responsivo
- **React Resizable Panels** - Painéis redimensionáveis
- **Recharts** - Gráficos e visualizações

### Formulários e Validação
- **React Hook Form 7.71.2** - Gerenciamento de formulários
- **@hookform/resolvers 5.2.2** - Resolvedores de validação
- **Zod 3.24.2** - Validação de schemas

### Utilitários
- **Date-fns 4.1.0** - Manipulação de datas
- **Class Variance Authority** - Gerenciamento de variantes CSS
- **Clsx** - Utilitário para classes CSS condicionais
- **Tailwind Merge** - Merge inteligente de classes Tailwind
- **Sonner** - Notificações toast
- **Input OTP** - Componente de entrada OTP
- **Vaul** - Drawer component

### Backend/Deployment
- **Cloudflare Workers** - Serverless computing
- **@cloudflare/vite-plugin** - Plugin Vite para Cloudflare
